# Balistik Tehdit Simülasyonu

Orta evredeki tehdit kümesinde gerçek harp başlığını fiziksel imzasından ayırt eden ve hedefleri önceliklendiren, eğitim amaçlı web simülasyonu ile temsilî bir MRV roket modeli.

- **Simülasyon:** https://bgelegen.github.io/balistik-tehdit-simulasyonu/
- **3B MRV modeli (burun konisi kapalı/açık):** https://bgelegen.github.io/balistik-tehdit-simulasyonu/model/

Modeldeki ölçüler temsilîdir, gerçek bir sisteme ait değildir.
